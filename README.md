# ⚽ Fluminense FC — Dashboard Power BI | Temporada 2026

Dashboard desenvolvido no **Power BI** para análise do desempenho do Fluminense FC durante a temporada de 2026.

![Dashboard Fluminense](Captura%20de%20tela%202026-08-30%20191106.png)

## 📊 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de transformar dados da temporada do Fluminense em informações visuais e de fácil interpretação.

O dashboard permite acompanhar os principais indicadores de desempenho da equipe e analisar sua evolução ao longo da temporada.

## 📈 Principais análises

- Partidas disputadas
- Vitórias, empates e derrotas
- Aproveitamento da equipe
- Gols marcados e sofridos
- Desempenho por competição
- Evolução ao longo da temporada

## 🛠️ Ferramentas utilizadas

- Microsoft Power BI
- Power Query
- DAX
- Modelagem de dados
- Visualização de dados

## 💡 Competências desenvolvidas

- Tratamento e transformação de dados
- Criação de medidas e KPIs
- Modelagem de dados
- Construção de dashboards
- Data Visualization
- Data Storytelling
